# Serene Soy Co. 🌿🕯️

Welcome to the official website for **Serene Soy Co.**, a handmade soy wax candle brand.  
This site is built with **HTML, CSS, and JavaScript** and is hosted on **GitHub Pages**.

## About
Serene Soy Co. specializes in eco-friendly, small-batch candles:
- 100% soy wax
- Lead-free cotton wicks
- Clean, phthalate-free fragrances
- Recyclable glass jars & sustainable packaging

- **About** — Our story, values, and wholesale/custom info
- **Contact** — Simple contact form
